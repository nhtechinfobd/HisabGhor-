# হিসাব ঘর (HisabGhor)

আপনার দৈনিক আয়-ব্যয় ও হিসাব রাখার একটি সহজ, নিরাপদ এবং স্মার্ট অ্যাপ। এটি সম্পূর্ণ অফলাইনে কাজ করে, আপনার ডেটার সম্পূর্ণ নিয়ন্ত্রণ আপনার হাতেই।

## ✨ প্রধান বৈশিষ্ট্য (Features)

*   **📊 ড্যাশবোর্ড ও চার্ট**: চার্টের মাধ্যমে ব্যয়ের ধরন এবং আয়-ব্যয়ের প্রবণতা এক নজরে দেখুন।
*   **🔒 নিরাপত্তা**: PIN লক এবং ফিঙ্গারপ্রিন্ট আনলক সমর্থন করে, আপনার আর্থিক তথ্য সুরক্ষিত রাখে।
*   **📄 PDF/CSV রিপোর্ট**: যেকোনো সময়ের লেনদেন রিপোর্ট তৈরি করুন এবং শেয়ার করুন।
*   **☁️ ব্যাকআপ ও রিস্টোর**: এক ক্লিকে JSON ফাইলে ব্যাকআপ নিন, ফোন পরিবর্তন করলেও ডেটা হারাবে না।
*   **🌙 ডার্ক মোড**: সিস্টেম, লাইট এবং ডার্ক থিম সমর্থন করে।
*   **🔔 দৈনিক রিমাইন্ডার**: প্রতিদিন নির্দিষ্ট সময়ে হিসাব রাখার কথা মনে করিয়ে দেয়।
